# Sample Workspace

A throwaway workspace bundled with the twinki file-editor example. Everything
here is safe to edit: the editor is scoped to this folder, so your changes only
touch these demo files. Reset anything with `git checkout`.

- `src/` — a tiny React-ish app (tsx + ts)
- `styles/` — CSS with custom properties
- `scripts/` — a bash build script
- `notes.md` — a markdown scratchpad

Open a few different file types and rotate the syntax theme with Tab to see the
highlighting change.
