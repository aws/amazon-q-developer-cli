# findings/ — one file per finding

Workers write one `.md` file **per finding** here, not per work item. File naming:

```
<work-item-id>-<YYYYMMDD>-<HHMM>-<short-slug>.md
```

Marker files track work-item completion and are distinguished by their slug:

```
<work-item-id>-<YYYYMMDD>-<HHMM>-done.md            # all techniques run
<work-item-id>-<YYYYMMDD>-<HHMM>-continuation.md    # budget exhausted
<work-item-id>-<YYYYMMDD>-<HHMM>-runbook.md         # deferred runbook
```

The rollup stage reads every `.md` here except `_rollup.md` (which it writes)
to produce a deduplicated, ranked report. See `../rollup.md` for the output
shape and `../work-item.template.md` for the finding-file schema.

This file exists to keep the directory in git. Delete it once real findings
are being produced.
