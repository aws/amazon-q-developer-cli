# Community Contribution Reports

Weekly snapshots of external-contributor PR activity for `kiro-team/kiro-cli`,
generated by the [`community-contribution-report`](../../.kiro/skills/community-contribution-report/SKILL.md)
skill.

## Contents

- `YYYY-MM-DD.md` — human-readable Markdown report (Slack-ready).
- `YYYY-MM-DD.json` — machine-readable snapshot the next run reads to compute
  weekly deltas. **Do not delete old snapshots** — history rebuilds are
  expensive.

## Generating

Ask Kiro CLI (with the skill loaded):

> "Generate the community contribution report"

or run the script directly:

```bash
python3 .kiro/skills/community-contribution-report/generate_report.py
```

The script auto-picks the most recent prior snapshot for the delta table. See
the [skill SOP](../../.kiro/skills/community-contribution-report/SKILL.md) for
the full parameter list.

## Cadence

Once per week, before Kiro CLI office hours. Report titles use the run date
(the "as-of" date), and the contribution-model start window is `2026-06-15`.
